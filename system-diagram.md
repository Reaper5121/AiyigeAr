# Aiyige System Context Diagram

The completed diagram is available as [system-diagram.svg](system-diagram.svg). It is a Level 0 data flow diagram for the Aiyige Wall and Ceiling Panel Customization and Sales System.

The diagram uses only the roles and capabilities present in this project:

- Customer: browses and customizes panels, receives an in-app quotation before order confirmation, chooses J&T or Lalamove and a payment method, and receives order and payment-status information.
- Administrator: manages user accounts, staff accounts, panel catalog records, and pricing; receives dashboard, record, quotation, and sales information.
- Staff: maintains inventory and records preparation and delivery progress for customer orders; receives order and payment-status information. The customer chooses the courier.
- Owner: provides business instructions and receives summarized sales, inventory, and payment reports.

Arrows point toward the recipient of each data flow. The routes use dedicated lanes so no line or label overlaps another.
